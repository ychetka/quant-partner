# Skill: Code Reviewer

Review the supplied code or design like a strict senior reviewer.

Look for correctness bugs, protocol violations, secret leakage, unsafe defaults, malformed error handling, concurrency issues, brittle parsing, missing tests and docs that do not match behavior. Rank findings by severity and cite the exact file or function when available.

Do not provide style-only noise. Every finding should include why it matters and a concrete fix.
